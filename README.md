# UniSupport – Student Support Management System

Bài làm môn Software Project Management: hồ sơ quản lý dự án xây dựng hệ thống tiếp nhận và xử lý yêu cầu hỗ trợ sinh viên cho Aurora University (khách hàng mô phỏng). Sinh viên gửi yêu cầu và theo dõi tiến độ, nhân viên phòng ban xử lý, ban quản lý theo dõi bằng báo cáo.

- **Tài liệu:** bắt đầu từ [mục lục `docs_v2/README.md`](docs_v2/README.md) (thứ tự đọc, vị trí scope, nguồn lực, rủi ro, change request, Definition of Done).
- **Kế hoạch công việc:** tab Issues và Milestones (`MS-01` đến `MS-06`) của repo này.
- **Cách làm việc trên repo:** [Team Charter](docs_v2/management/team-charter.md) mục 9 (nhánh, Pull Request, review, merge); mẫu issue và PR trong `.github/`.
