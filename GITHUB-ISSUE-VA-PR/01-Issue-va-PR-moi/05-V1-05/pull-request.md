# V1-05 · Áp dụng review độc lập và một PR mỗi hạng mục

## Tóm tắt thay đổi

- **Mã hạng mục / rà soát** V1-05
- **Nội dung thay đổi** Điền đầy đủ mẫu PR, liên kết issue, mời người review khác tác giả và squash sau khi duyệt. Quy định cách xử lý phần sửa nhỏ.

## Liên quan

- **Issue đóng / cập nhật** Closes #<issue mới của mục này>
- **Mã liên quan** Team Charter mục 9

## Tài liệu Word / Excel / PDF đã đổi

Không.

## Bằng chứng kiểm tra

- **Người review khác tác giả** Đề xuất Đào Tuấn Bảo hoặc người dự phòng theo Team Charter. Cập nhật tên và bằng chứng khi đã duyệt.
- **Hình thức gộp sau khi duyệt** Squash and merge.
- **Mục lục và liên kết** Đã rà bộ hồ sơ tích hợp, liên kết GitHub có tag cần mở thử sau khi tag được phát hành.
- **Tài liệu dẫn lại** Team Charter mục 9 và mẫu Pull Request.
- **Kiểm tra thực tế, gồm Excel nếu có** Đã kiểm tra mẫu PR và cấu trúc 12 commit riêng. Nhà quản lý GitHub xác nhận lượt Approve trước khi gộp.
