# V1-05 · Áp dụng review độc lập và một PR mỗi hạng mục

## Phạm vi

Điền đầy đủ mẫu PR, liên kết issue, mời người review khác tác giả và squash sau khi duyệt. Quy định cách xử lý phần sửa nhỏ.

## Tiêu chí chấp nhận

- [ ] Đối chiếu team Charter mục 9 và mẫu Pull Request.
- [ ] Xác nhận bằng chứng kiểm tra ghi trong PR. Đã kiểm tra mẫu PR và cấu trúc 12 commit riêng. Nhà quản lý GitHub xác nhận lượt Approve trước khi gộp.
- [ ] Người khác tác giả Approve.
